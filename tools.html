🤖 Tools Bot Telegram

Bot Telegraf dengan berbagai tools. Kirim perintah berikut ke bot Telegram Anda.

/start

Sambutan & menu

/help

Daftar perintah

/materi

Daftar materi TIK

/qrcode <teks>

Generate QR Code

/wiki <query>

Cari di Wikipedia

/kurs

Kurs USD, SGD, MYR

/cuaca <kota>

Info cuaca realtime

/id

Info user Telegram

/ping

Cek latency bot

🚀 Cara Menjalankan Bot

  1. Chat @BotFather di Telegram → /newbot
  2. Salin token ke file .env
  3. Jalankan: npm run bot
  4. Chat bot Anda & ketik /start
